Məxfilik Siyasəti

Son yenilənmə: 2026-08-19

Bu Məxfilik Siyasəti SECURITY GROUP tərəfindən hazırlanmış tətbiqin (bundan sonra — "Tətbiq") istifadəçi məlumatlarını necə topladığını, istifadə etdiyini və qoruduğunu izah edir. Tətbiq TikTok API vasitəsilə sosial media hesablarının idarə edilməsi üçün nəzərdə tutulub.

Topladığımız məlumatlar

  • TikTok hesab identifikasiyası (istifadəçi ID, hesab adı, profil şəkli)
  • TikTok tərəfindən verilən giriş token-ləri (access token, refresh token) — hesabınıza icazə verdiyiniz əməliyyatları yerinə yetirmək üçün
  • Paylaşılan kontentin performans göstəriciləri (baxış, bəyənmə, şərh sayı) — yalnız analitika məqsədilə
  • Tətbiq daxilində yaratdığınız kontent (video, şəkil, mətn) — planlaşdırma və paylaşım üçün

Məlumatlardan necə istifadə edirik

  • Sizin icazə verdiyiniz kontentin TikTok hesabınızda planlaşdırılması və paylaşılması
  • Hesabınızın performans analitikasının göstərilməsi
  • Tətbiqin funksionallığının təmin edilməsi və təhlükəsizliyin qorunması

Məlumatlarınız üçüncü tərəflərə satılmır və ya reklam məqsədilə paylaşılmır.

Məlumatların saxlanması və təhlükəsizliyi

Giriş token-ləri şifrələnmiş formada saxlanılır. Yalnız icazə verdiyiniz əməliyyatlar üçün istifadə olunur. İstənilən vaxt icazənizi TikTok tənzimləmələrindən ləğv edə bilərsiniz — bu, Tətbiqin hesabınıza girişini dərhal dayandırır.

Məlumatların silinməsi

Hesabınızı Tətbiqdən ayırdıqda və ya bizimlə əlaqə saxlayıb tələb etdikdə, sizə aid bütün saxlanılan məlumatlar 30 gün ərzində silinir.

Uşaqların məxfiliyi

Tətbiq 18 yaşdan aşağı şəxslər üçün nəzərdə tutulmayıb və onlardan bilərəkdən məlumat toplamır.

Siyasətdə dəyişikliklər
