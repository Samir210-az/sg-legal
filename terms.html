İstifadə Şərtləri

Son yenilənmə: 2026-08-19

Bu İstifadə Şərtləri SECURITY GROUP tərəfindən hazırlanmış tətbiqin (bundan sonra — "Tətbiq") istifadəsini tənzimləyir. Tətbiqi istifadə etməklə aşağıdakı şərtləri qəbul etmiş olursunuz.

Xidmətin təsviri

Tətbiq TikTok API-dən istifadə edərək sosial media kontentinin planlaşdırılması, paylaşılması və performans analitikasının izlənməsi imkanını təqdim edir. Xidmət yalnız istifadəçinin özünün icazə verdiyi TikTok hesabları üzərində işləyir.

İstifadəçi öhdəlikləri

  • Tətbiq vasitəsilə paylaşılan bütün kontentə görə istifadəçi özü məsuliyyət daşıyır
  • TikTok-un öz İstifadə Şərtləri və İcma Qaydalarına riayət edilməlidir
  • Tətbiq spam, aldadıcı və ya qanunsuz kontent yaymaq üçün istifadə edilə bilməz
  • Hesab girişi məlumatları (token, şifrə) üçüncü şəxslərlə paylaşılmamalıdır

Xidmətin məhdudiyyətləri

Tətbiq TikTok-un API rate-limit qaydalarına tabedir. Bəzi funksiyalar TikTok tərəfindən dəyişdirilə və ya dayandırıla bilər — bu, Tətbiqin nəzarətindən kənardır.

Hesabın ləğvi

İstifadəçi istənilən vaxt TikTok hesabının Tətbiqə girişini ləğv edə bilər. Şərtlərin pozulması halında Tətbiq tərəfindən istifadəçinin girişi məhdudlaşdırıla bilər.

Məsuliyyətin məhdudlaşdırılması

Tətbiq "olduğu kimi" təqdim olunur. SECURITY GROUP, TikTok platformasının özündə baş verən nasazlıqlara, məlumat itkisinə və ya üçüncü tərəf xidmətlərinin fəaliyyətinə görə məsuliyyət daşımır.

Şərtlərdə dəyişikliklər

Bu Şərtlər vaxtaşırı yenilənə bilər. Əhəmiyyətli dəyişikliklər bu səhifədə dərc olunacaq.
